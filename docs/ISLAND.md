# Island 灵动岛

## 目标与参考

Island 将 Pin 任务融入 Mac 的屏幕刘海，悬停时向下展开任务条目。参考 [Atoll](https://github.com/Ebullioscopic/Atoll) 的顶边定位、刘海避让与展开交互；本项目使用自己的 Rust/GPUI 任务 UI 和 AppKit 桥接，不引入 Atoll 的源码或依赖。

参考代码位置：`DynamicIsland/components/Notch/DynamicIslandWindow.swift`、`DynamicIsland/sizing/matters.swift`、`DynamicIsland/components/Calendar/ReminderLiveActivity.swift`。关键是按物理屏幕顶边定位，读取 `safeAreaInsets` 与左右 `auxiliaryTop…Area`，在摄像头两翼放内容。

## 交互

- 侧栏 Island、视图菜单、⌘⇧I 或设置 → 实验开关；默认关闭，状态持久保存。
- 有刘海的屏幕优先，收起态高度严格等于系统报告的刘海高度，不再额外加 4pt 或设 32pt 下限；无刘海时，虚拟岛最多 26pt，并且不超过系统菜单栏厚度。当前 30pt 菜单栏下收起高度为 26pt，明显矮于菜单栏下沿。
- 岛体固定黑色，与物理摄像头区域融为一体；小精灵的单色身体及强调色随应用设置，脚边小球固定使用应用图标配色。收起态左侧为原创 9×9 像素小精灵，保留触角、手脚和表情，搭配 7×7 像素的浅灰白底四色小球；小球以 `#E5E5E5` 边框和中央十字承托红、蓝、橙、灰四格，比纯白柔和、比中灰明亮，右侧为 3×5 点阵数字，中间保留摄像头空区。按实际像素网格绘制，不依赖额外字体或图片。两翼内容整体上移 1px，精灵和小球占用左翼内固定的 36×24pt 区域，完整运动轨迹不进入摄像头空区。最多显示 `99+`，悬停数字可查看完整数量。
- 鼠标移入或数量变化时，小精灵播放一次 640ms 的轻跳与眨眼；空列表时呈低亮度休息状态。数字变化时短暂跳动 240ms。单次动作不循环，不改变岛体高度，遵循系统减少动态效果。
- 收起且未悬停时，每隔 18、26、22 秒交替触发一次 2.4 秒原地颠球：抬脚挑起小球，球在脚上方沿两段竖直弧线升降，落下时再次颠起，最后接球回位。悬停、展开、数量变化及完成庆祝优先，中止颠球；减少动态效果开启时不触发。等待期间只保留低频定时器，不请求动画帧；关闭 Island 时取消定时任务。
- 悬停 140ms 后向下展开，移开 420ms 后收起。300ms 缓动形变和内容淡入，快速移入展开目标区域不误触发收起。静止时不循环请求动画帧；遵循系统减少动态效果。
- 展开是一列任务，无备注、进展或详情栏。每行有完成按钮、标签与标题、简短日期和必要的父任务提示。标签沿用主列表的彩色文字样式，按任务标签顺序显示在标题前，不添加 `#`；标签与标题合计最多两行，超出以省略号收尾，只有实际显示不全时才在悬停时显示完整标签与标题。取消 Pin 统一在主窗口进行。双击或 Enter 打开原有任务窗口。按住 Option 时，带链接的标题显示强调色与下划线；Option＋单击复用主应用的草稿保存与链接打开逻辑，保存成功后打开最新的第一条链接，失败时保留草稿并在岛内显示错误。
- 高度随任务数变化，最多五行，更多条目滚动；五条以内每减少一条收缩一行，单条任务不再预留第二行，空列表提示也只占一行高度。列表底部不显示操作提示行，展开高度也相应减少。上下键选择时自动滚动到选中项，Esc 收起。
- 完成后小精灵变为笑脸，出现像素闪光和 `+1`，并复用完成撒花。撒花期间条目显示完成勾选与标题删除线，保留原位置及所占高度；撒花结束后才移除条目，并按剩余条目数收缩面板。关闭撒花或开启系统减少动态效果时，条目立即移除。所有持久变更仍经 Workspace::change → Store::save，保存成功才更新列表及播放反馈；错误显示在岛内。
- 所有周的未完成 Pin 都可见，不受主页面周、搜索或标签筛选影响；共享原有 Pin 数据，不创建副本。关闭主窗口保留 Island，应用继续运行。
- 主窗口红色关闭按钮、⌘W 和“关闭窗口”只在保存成功后隐藏该窗口，保留任务状态、撤销历史及原生编辑会话；任务窗口可以独立关闭。点击 Dock 图标、视图 →“显示主窗口”或 Island 的返回按钮恢复主窗口。⌘Q 和“退出 FourQuadrants”才退出应用，仍执行草稿保存与富文本会话检查，失败时显示主窗口中的错误。

## 实现

`src/app/island.rs` 负责列表、选择、形状和动画，`src/app/island/pixels.rs` 绘制像素精灵和计数器。`native/WindowMaterial.m` 负责屏幕安全区域、非激活面板、顶边坐标、菜单栏上方的窗口层级与异步尺寸调整。原生调整合并请求，关闭后丢弃待执行操作；收起结束时缩小实际窗口，不留下常驻的大块透明命中区。屏幕配置变化重新选屏、调整位置和刘海避让尺寸。

不改变 GPUI 版本、数据 schema、主窗口主题和原版 SwiftUI 数据。旧版 Island 的左右两栏详情已经移除，包括曾导致重复 hover 断言的完成按钮构造；新条目不使用该按钮组合。

## 验证与预览

```sh
bash scripts/preview-island.sh dark
```

参数 `light` / `system` 改变主窗口主题；Island 保持黑色。每次生成新的 target/ 合成数据，不操作正式任务、系统通知或更新。调试构建可用 `FOUR_QUADRANTS_PREVIEW_ISLAND=expanded` 搭配 `--data` 检查展开态。

- Rust 测试覆盖：有/无刘海布局、摄像头空区、列表高度上限、小屏约束、跨周 Pin、稳定选中、可反向动画、设置兼容。
- 原生测试覆盖：物理顶边和副屏坐标、菜单栏上方层级、无焦点抢占的创建、异步合并尺寸调整、关闭取消回调、窗口释放。
- 真实隔离应用已通过非空列表及浅色主窗口空列表各三轮开合；调用同一悬停处理，覆盖计时器、真实渲染和原生窗口尺寸。收起高度修正后再次通过非空列表三轮 184×30 ↔ 440×342 开合，无 panic；收起与当前 AppKit 菜单栏 30pt 一致，物理顶边 `y=0`。
- 使用仅加载到隔离调试进程的 AppKit 驱动，验证红色关闭按钮、Dock reopen 回调（Island 开/关）、“关闭窗口”与“显示主窗口”菜单，以及主窗口不可见时的退出菜单和 ⌘Q 菜单快捷键；两个进程均正常退出。另验证 Island 获得焦点、主窗口隐藏时，“设置”和“新建任务”菜单能恢复主窗口并执行命令。该驱动不模拟系统鼠标，也不操作其他应用。
- 像素版在 0、12、100 条合成任务下各通过三轮真实 GPUI 开合，覆盖空状态、两位数字和 `99+` 上限。当前 30pt 菜单栏下，收起为 184×26；两行标题使用 56pt 行高，0 条展开为 440×182，达到五行上限后为 440×350。像素图案另有离线绘制检查，不作为应用截图。
- 调试开合检查原先在固定 900ms 后断言动画结束，任务较多时因计时器延后导致测试进程 abort；现在等待动画与原生尺寸实际稳定，每步最多 10 秒，超时记录 `Island preview FAILED`，不在 GUI 回调中 panic。检查仍仅在 debug + `--data` + 显式 `cycle` 环境变量下启用。
- Option 链接交互使用新的 12 条合成任务与仅加载到该预览进程的 AppKit 驱动验证：打开第一条链接、无链接时不跳转、普通单击选择、双击任务窗口、跨窗口保存草稿，以及并发写入失败时阻止打开并保留任务窗口。驱动拦截 URL 请求，不启动浏览器；事件只发给该进程的 GPUI 视图，不代表真实系统按键和鼠标验收。
- 两行标题调整后，隔离应用中的 111 字中文任务标题在详情输入框内排成五行，逐字检查文字坐标均处于输入框可见区域；同时复验 Option 链接、双击打开详情、草稿保存和并发写入失败保护。该检查验证布局与交互，不替代截图观感验收。
- Rust 125 项测试、格式检查、Clippy、原生窗口测试、helper 自测及更新退出保护回归通过。
- 当前可见屏幕没有物理刘海，不能声称实测物理刘海。辅助功能与屏幕录制未授权，实际鼠标、Dock 点击、截图和动画观感仍需实际验收。

Island 从 0.21.0 起提供，默认关闭，可在设置 → 实验中开启。

### 颠球动画验证

- 新增轨迹边界、回位与脚面触球测试，检查球体始终位于固定的 36×24pt 绘制区内，腾空期间保持原地升降，触球时球底与抬起的脚面相接。实际菜单栏动画观感及物理刘海屏幕仍需目视验收。
